# 标签体系（Tag Taxonomy）

> 最后更新：YYYY-MM-DD
> 本文件是知识库的标签注册表。所有标签在使用前必须在此注册。

---

## 一、内容类型（Content Type）

描述文档本身是什么形态。每篇文档**必须**有一个内容类型标签。

| 标签 | 说明 | 适用示例 |
|------|------|---------|
| `内容/文章` | 发布的长文、公众号文案 | 你发布的原创文章 |
| `内容/短内容` | 短视频脚本、短文案 | 口播稿、朋友圈文案 |
| `内容/工具框架` | 方法论模板、SOP | 复盘模板、工作流程 |
| `内容/竞品分析` | 同行/竞品分析报告 | 对标账号分析 |
| `内容/复盘笔记` | 工作复盘 | 项目复盘、活动复盘 |
| `内容/技术研究` | 技术/工具相关 | 工具评测、技术方案 |
| `内容/参考资料` | 外部资料整理 | 行业报告摘要 |
| `内容/课程笔记` | 学习课程的笔记 | 线上/线下课程记录 |

---

## 二、领域（Domain）

描述文档涉及的知识领域。每篇文档**至少**有一个领域标签。

> 以下为示例标签，请根据你的行业替换或新增。

| 标签 | 说明 |
|------|------|
| `领域/（你的主业）` | 你的核心业务领域 |
| `领域/（细分方向1）` | 细分方向 |
| `领域/（细分方向2）` | 细分方向 |
| `领域/技术` | 技术工具相关 |
| `领域/自媒体` | 内容创作、平台运营 |
| `领域/个人IP` | 个人品牌建设 |

---

## 三、系列（Series）

描述文档所属的系列。仅系列化内容使用。

> 以下为示例，请根据你的系列替换。

| 标签 | 说明 |
|------|------|
| `系列/（你的系列名）` | 你的内容系列总标签 |

> **新增系列规则**：当你发布 3 篇以上同主题内容时，可以注册新系列标签。格式：`系列/系列名`

---

## 四、状态（Status）

描述文档当前状态。可选。

| 标签 | 说明 |
|------|------|
| `状态/已发布` | 已在平台发布 |
| `状态/草稿` | 还在编辑中 |
| `状态/参考` | 仅供参考，不会发布 |

---

## 五、索引（Index）

用于索引页/目录页。

| 标签 | 说明 |
|------|------|
| `索引/素材合集` | 外部素材合集的索引页 |
| `索引/总目录` | 全局目录（index.md） |
| `索引/修改日志` | 修改日志文档 |

---

用于区分特定页面类型，配合 frontmatter 的 type 字段使用。

> 以下为示例，请根据你的行业替换。

| 标签 | 说明 |
|------|------|
| `类型/产品页` | 具体产品/服务的知识页（示例） |

## 标签使用规则

1. **每篇文档 2-6 个标签**：1个内容类型 + 1-2个领域 + 可选的系列/状态
2. **层级用 `/` 分隔**：如 `领域/技术`
3. **新标签先注册**：在本文件对应类别下添加一行，再使用
4. **不要创建一次性标签**：如果一个标签只会用一次，考虑用其他方式表达
5. **标签命名统一用中文**：除非是专有名词（如 AI）
6. **frontmatter 优先于标签**：以下信息用 frontmatter 字段表达，不用标签：文档状态（status）、内容来源（source_origin）、复查周期（review_cycle）
