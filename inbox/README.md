# Inbox

`inbox/` 是临时暂存区，用于放置来源、用途、隐私边界或目标目录不清楚的材料。

## 使用规则

- 不确定归属时，先放这里并标记 `待人工确认`。
- 周度维护只检查文件名、frontmatter 和用户点名内容，不默认读取全部正文。
- 涉及隐私或敏感信息时，先脱敏或跳过。
- `inbox/` 不是长期知识目录，确认归属后再小批量归档。
