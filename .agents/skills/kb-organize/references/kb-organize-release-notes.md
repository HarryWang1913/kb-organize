# kb-organize 版本说明

## 当前版本

`kb-organize v0.4-public-starter`

## 能力范围

- Obsidian root canonical 维护。
- resolver 分流。
- `inbox/` 暂存。
- README 稳定化。
- 概念页轻量维护。
- `index.md` / `sources.md` / `log.md` 维护。
- 私有同步和 GitHub 发布前隐私规则。
- 外部素材只读边界。
- 周度维护和 lint 检查。

## 公开仓库边界

可公开：

- 通用规则。
- 通用 Skill。
- 空白模板。
- 脱敏示例。
- 维护流程说明。

不应公开：

- 个人业务资料。
- 客户、合同、保单、证件、联系方式、财务账户、医疗记录。
- 私人日程和执行细节。
- 未确认可公开的课程、文章、转写稿或外部资料全文。
