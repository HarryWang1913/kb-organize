# 私有知识库同步策略

## 定位

- 知识库默认是个人私有 Obsidian Vault。
- GitHub 是可选发布方式，不是默认同步方式。
- 可使用本地磁盘、Obsidian Sync、NAS、个人云盘或私有仓库同步。

## 多设备规则

- 同一时间只允许一台机器运行 AI 写入。
- 写入前确认同步已完成。
- 写入后等待同步完成，再换设备继续编辑。
- 大批量修改前，先做快照、整库复制或云盘版本备份。

## GitHub 发布规则

- 发布前先做隐私扫描。
- 不上传客户、合同、证件、联系方式、财务账户、医疗记录、保单或私人日程。
- 不上传个人业务正文，除非已经确认可公开。
- 可公开发布的是规则、模板、脱敏示例、通用 Skill 和空白启动结构。

## 冲突规则

- 发现冲突文件、重复文件、带 `conflict` 字样的同步副本，先报告，不自动合并。
- 不写入绝对路径、本机用户名、设备名或 NAS 绝对路径。
