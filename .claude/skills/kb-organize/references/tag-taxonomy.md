# Tag Taxonomy

This is a starter tag registry. Customize it before applying tags broadly.

## Content Type

| Tag | Meaning |
|---|---|
| `内容/原创文章` | User-authored long-form content |
| `内容/短内容` | Short posts, scripts, snippets |
| `内容/工具框架` | Frameworks, templates, SOPs |
| `内容/参考资料` | Reference material summaries |
| `内容/课程笔记` | Course or learning notes |
| `内容/项目文档` | Project requirements, design, implementation notes |

## Domain

| Tag | Meaning |
|---|---|
| `领域/AI` | AI tools, AI trends, knowledge systems |
| `领域/自媒体` | Content creation and media operation |
| `领域/产品` | Products, product thinking, user experience |
| `领域/商业` | Business models, sales, strategy |
| `领域/学习` | Learning notes and study systems |
| `领域/个人成长` | Review, habits, execution, expression |

## Status

| Tag | Meaning |
|---|---|
| `状态/草稿` | Draft |
| `状态/已发布` | Published |
| `状态/参考` | Reference-only |
| `状态/待确认` | Needs human confirmation |

## Index

| Tag | Meaning |
|---|---|
| `索引/总目录` | Global index |
| `索引/来源` | Source or external material index |
| `索引/维护` | Maintenance report or log |

## Core

| Tag | Meaning |
|---|---|
| `概念` | Concept hub pages |
| `规则/同步` | Sync and publishing rules |
| `规则/隐私` | Privacy rules |

## Rules

1. Use 2-6 tags per maintained page.
2. Use one content-type tag and at least one domain tag when possible.
3. Use `/` for hierarchy.
4. Register new tags here before applying them broadly.
5. Avoid one-off tags.
6. Do not encode private customer data, IDs, contact information, or sensitive facts in tags.
